# fiddlerstrike
Проект посвящен разработке шутера. В этом шутере в будущем будет много режимов, и разных функций. Сейчас, на данном этапе разработки, нам нужно добавить на Unity Engine локацию из магазина 3D моделей SketcFab. Задача состоит в том, что нужно импортировать модели с текстурами. Дальше, мы должны будем добавить ботов, которые будут временно мирными. Потом мы должны будем добавить модель персонажа для игрока, и для ботов. Потом нужно будет добавить 3D модели оружия. И только потом, добавить анимированную стрельбу по ботам и наоборот, а так же настройку их сложности. Потом, нам нужно будет добавить анимацию на ходьбу, стрельбу, перезарядку и т.д. И только потом делать дополнительные функции: Меню, Лобби, Друзья, Инвентарь, Рынок, Скины.
